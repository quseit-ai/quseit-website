QBuilder Desktop 控制面板完全指南

面向普通用户的控制面板说明。逐个介绍 Dashboard、Chat、Tasks、Channels、Skills、Memory、Spaces、Agent profiles、Skill Studio、Settings 共 10 个核心模块的作用、入口与典型用法,帮你从零熟悉 QBuilder 的工作台。

入门 · BEGINNER 约 8 分钟读完 实操约 15 分钟 最后更新 2026-09
QBuilder 是给谁的? 给知识工作者的「AI 工作室」 — 教师、咨询师、律师、销售、培训师、独立顾问这类日常产出是「问答、建议、内容、方案」、而不是软件的人。它解决的不是「如何写 prompt」,而是「如何把『我脑子里那套方法论』变成一个能被客户随时用的产品」。

本教程适合谁? 刚装好 QBuilder Desktop、第一次打开浏览器看到左侧一列图标的用户。读完后能:

  • 知道每个导航图标对应什么功能、什么时候该用
  • 理解 Dashboard 与 Chat 的关系(同一份 composer,两套上下文)
  • 在 Skills / Skill Studio / Settings 之间找到正确的入口

模块总览

QBuilder Desktop 的左侧导航栏一共有 10 个图标(8 个主视图 + 2 个工具入口)。下面这张表先用一句话说清每个模块干什么,然后下面一节一节展开。

# 图标位置 模块 一句话作用 常驻
1左侧仪表盘 (Dashboard)启动首页:5 类工作流入口卡 + 共享输入框常驻
2左侧对话 (Chat)主对话区:消息流、附件、模型/工作区/推理 chip常驻
3左侧任务 (Tasks)定时任务(cron):自动跑对话或脚本的调度表常驻
4左侧渠道 (Channels)网关渠道:把对话接到 Telegram/微信/企微 等第三方常驻
5左侧技能 (Skills)技能库:本机已装技能 + 技能商店常驻
6左侧记忆 (Memory)记忆:我的备注、用户画像、智能体灵魂等持久记忆常驻
7左侧工作区 (Spaces)工作区:多目录项目切换器常驻
8左侧代理配置 (Agent profiles)配置档案:同一台机器上多个 Agent 预设(模型 + 提示词 + 工具)常驻
9左侧技能创作 (Skill Studio)技能创作:用 AI 把想法/文档/导入物变成可加载技能常驻
10左侧设置 (Settings)设置:9 个子分页(外观、偏好、提供商、账户…)常驻

关键约定 · 第一次用 QBuilder 必须知道

  • 技能创作 / 设置两个图标不是普通导航 — 技能创作是「生产」、设置是「配置」,它们被故意放在左侧导航的偏下位置,提醒你这是工具不是主流程。
  • 仪表盘与对话共享输入框 — 在仪表盘输入并发送,会自动跳到对话继续,不会有两套输入体验要适应。
  • 技能 / 工作区 / 配置档案 三者正交 — 一个 profile 可以跨多个 workspace 用,一个 workspace 里可以装多个技能。混搭任意。
  • 记忆自动读写 — 你不需要每次手动喂背景,AI 在合适的时机自动调 memory 工具。
  • 任务调度需要渠道网关在跑 — 如果你发现任务没自动触发,先去渠道看看网关状态。
  • 技能创作的 4 个入口对应 4 种创建场景 — 导入 = 已有技能 / 学习 = 文档转技能 / AI 创建 = 想法转技能 / 工作流(即将推出)。

1 · 仪表盘 (Dashboard) — 启动首页

01

仪表盘 (Dashboard) 是什么?

Dashboard 是打开 QBuilder Desktop 后的第一个页面。它把整个产品最常用的入口摆在你面前,不必到处找。

01-dashboard.png · Dashboard 启动态:5 类工作流入口卡 + 共享 composer

典型元素

  • 侧栏:左侧 10 个图标,本教程后续每个模块都会讲到。
  • 历史会话列表:左下侧是按「今天 / 昨天 / 上周 / 更早」分组的历史对话,点击可恢复。
  • 5 类工作流入口卡:中央上半部分是 5 张大卡片。本指南只展开其中「🚀 技能构建」(对应第 9 节「技能创作」);「⚙️ 软件项目 / 🔬 质量保障 / 🎨 内容工厂 / 📦 交付上线」对应 QUSEIT 五大行业实战手册场景,在 用例库 里展开,本篇不深入。
  • 共享 composer(输入框):Dashboard 中央下半部分就是 Chat 用的同一个输入框 — 在 Dashboard 里输入并发送,会自动切到 Chat 继续对话。
  • 底部工具条:右下角的 profile chip(显示当前 Agent)、模型 chip、推理强度 chip、发送按钮。
  • 右下角 User Guide 入口:新手指引卡,首次启动会弹出。
什么时候用? 不知道从哪开始时,首选 Dashboard — 它是「引导 + 入口 + 快速提问」三合一的首页。

2 · 对话 (Chat) — 主对话区

02

对话 (Chat) 是什么?

Chat 是真正发生对话的地方。Dashboard 上的 composer 点发送后会跳到 Chat 并继续;直接从侧栏进 Chat 也是同一个界面。

02-chat.png · Chat 区:历史会话侧栏 + 消息流 + 完整工具条

典型元素

  • 历史会话侧栏:左下侧列出本工作区下的全部对话,带时间分组 + 工作区标签。
  • 工作区切换:顶部「全部 / workspace」chip,点 + 可以建新工作区(对话分类)。
  • 消息流:主区域。AI 回复、人类消息、工具调用卡片、审批请求都会按时间顺序显示。
  • 快速建议卡:新会话时会出现 4–5 张快捷任务卡(如「从向导构建技能」「从文档生成技能」「通过 YAO 框架构建技能」「转换为 Workbuddy 技能」)。
  • 输入框(composer):支持多行输入、回车发送、Shift+回车换行。
  • 工具条:
    • 📎 附件按钮:挂文件 / PDF / 图片
    • 🎙️ 听写按钮:语音转文字输入
    • Saved prompts:常用提示词模板
    • profile chip:切换 Agent 配置档案
    • workspace chip:切换当前工作目录
    • model chip:切换模型(如 MiniMax-M3 / Claude / GPT)
    • reasoning chip:切换推理强度(Default / High / Off)
    • ↑ 发送键:发送消息
什么时候用? 几乎所有「我想让 AI 干活」的场景都在 Chat 里。Dashboard 是入口,Chat 才是执行。

3 · 任务 (Tasks) — 定时任务

03

任务 (Tasks) 是什么?

Tasks 是 QBuilder 的「定时任务调度器」,学名 cron jobs。它让你设定一些「每天早上 8 点跑一次」「每小时汇总一次数据」之类的自动化任务,QBuilder 会按计划自动启动新的对话或脚本。

03-tasks.png · Tasks 侧栏 + 主区「选择一个计划任务」占位

典型元素

  • 侧栏列表:按 active(运行中) / paused(已暂停) 分组。右上角 ↻ 刷新 + + 新建任务。
  • 主区详情:点击左侧某个任务,右侧会展示它的运行记录(成功 / 失败 / 重试)与配置(触发时间、提示词、目标工作区)。
  • 网关依赖提示:Channels 没启动时,这里会显示一条提示告诉你先去配网关。
典型场景: 你希望 AI 每天 9 点自动跑一遍前一天的工作总结,或者每周一汇总本周 GitHub Issues — 设好 cron,QBuilder 不用你开浏览器就会按节奏自动启动对话。

4 · 渠道 (Channels) — 网关渠道

04

渠道 (Channels) 是什么?

Channels 是把 QBuilder 对接第三方聊天平台的入口。它背后是一个 gateway 网关,可以监听 Telegram / Discord / Slack / 企业微信 / 微信 等渠道的消息,把对话路由到本机的 Agent。

04-channels.png · Channels 加载完成:网关配置侧栏(API 密钥 / Start) + 主区 4 张渠道卡(WhatsApp / 飞书 / 企业微信 / 微信) + 顶部「网关当前未运行」提示

典型元素

  • 侧栏「网关配置」:网关整体状态(已连接 / 离线 / 启动中)。
  • 主区「网关渠道」:渠道卡片网格 — 每张卡对应一个第三方平台,显示连接状态、配对链接、最近消息时间。
  • 配对按钮:首次接入某个渠道时,点配对会显示二维码或一次性配对码。
  • 右上角 ↻:手动刷新网关状态。
典型场景: 你希望客户在微信里直接问 AI 产品规格,而你不必每次手动转述;或者家长在企微群里直接问学生作业问题,AI 自动按你训练好的口径答复。

5 · 技能 (Skills) — 技能库

05

技能 (Skills) 是什么?

Skills 是 QBuilder 已经装好、可直接调用的技能合集。每个技能是一段 markdown 说明书 + 一组脚本,告诉 AI 「遇到这类问题应该这样做」。

05-skills.png · Skills「商店」tab + 首个技能 book-to-skill 详情卡(描述、版本、作者、SKILL.md 全文、安装按钮)

典型元素

  • 两个 tab:我的 Skill(本机已装)与 商店(可在线安装)。
  • 左侧分类:GENERAL / AUTONOMOUS-AI-AGENTS / CREATIVE / EMAIL / HUB 等,每类下面挂具体技能。
  • 搜索框:按名称模糊过滤。
  • 开关:每条技能右侧有一个开关 — 关掉后,AI 在对话里就不会调用这条技能。
  • 主区详情:点具体技能后,右侧会展示它的 SKILL.md、触发词、调用示例。
典型场景: 你想给 AI 装上一组扩展技能,让工作流程与处理能力贴合你的行业 / 团队需要 — 在这里启用、禁用、安装、搜索各类技能,AI 在后续对话里会自动调用它们。

6 · 记忆 (Memory) — 持久记忆

06

记忆 (Memory) 是什么?

Memory 是 QBuilder 跨会话的「长期记忆」。聊天时 AI 会自动读写这里的条目,下次再开会话它仍然记得。

06-memory.png · Memory 4 分项:我的备注 / 用户画像 / 智能体灵魂 / 项目上下文;「我的备注」选中,主区展示 MEMORY.md 真实条目

4 个分项

  • 我的备注 (memory):你给 AI 留的笔记、复述规则。
  • 用户画像 (user):AI 眼中的「你是谁」 — 偏好、习惯、角色。
  • 智能体灵魂 (soul):AI 自己的设定 — 人格、语气、底线。
  • 项目上下文 (project_context):只读,展示当前 workspace 的项目背景。
典型场景: 你希望 AI 越聊越懂你 — 在用户画像里写「我不喜欢 Markdown 表格」「回答用中文优先」,在智能体灵魂里调语气,这些会跨会话生效。

7 · 工作区 (Spaces) — 项目目录

07

工作区 (Spaces) 是什么?

Spaces(也叫 Workspaces)是「项目目录」。它把你电脑上不同的项目文件夹(比如 D:\Workspace\quseit-website 和 D:\Projects\qagent-desktop)区分开,切换工作区 = 切换 AI 当前能看到、操作的目录。

07-spaces.png · Spaces 第一个工作区 QBuilderWorkspace 详情:Name / Path / Status(Inactive)+ 检查点 section

典型元素

  • 侧栏:工作区列表 + 「+」新建按钮,每条显示名称 + 路径。
  • 工作区详情:点某个工作区,右侧展示该工作区的设置(默认模型、关联技能、文件树预览)。
  • 新建工作区:点 + 选本地文件夹,QBuilder 会把它注册成独立工作区,后续对话自动 scope 到该目录。
典型场景: 你同时在做多个项目(比如 quseit-website + qagent-desktop),每个项目有不同的依赖和文件,切换工作区 = AI 的视野自动切到对应目录。

8 · 代理配置 (Agent profiles) — 配置档案

08

代理配置 (Agent profiles) 是什么?

Agent profiles 让你为不同场景准备多个「Agent 预设」 — 每套预设 = (模型 + 系统提示词 + 启用技能 + 工具集)。切换 profile 就像换了一个「不同性格 + 不同技能」的助手。

08-agent-profiles.png · Profiles default 档案详情:Status / Gateway(已停止) / Model(MiniMax-M3) / Provider(minimax-cn) / API key / Skills

典型元素

  • 档案列表:左侧列出全部 profile,当前激活的会被高亮。
  • 档案详情:右侧展示该 profile 用了哪个模型、哪些技能开关、系统提示词摘要。
  • 新建档案:通常隐藏在高级菜单 — 单 profile 模式下不会显示。
典型场景: 你希望「开发场景用一个严谨的 agent,写作场景用一个随性的 agent」,每个场景建一个 profile,一键切换 — 不同场景的人格、模型、技能组合可以完全不同。

9 · 技能创作 (Skill Studio) — 技能创作工坊

09

技能创作 (Skill Studio) 是什么?

Skill Studio 是 Skills 面板的「创作端」 — Skills 管使用,Studio 管创建。一句话区别:Hub consumes / Skills manages / Studio creates(商店消费 / 技能管用 / 工坊生产)。

09-skill-studio.png · Studio 主页:4 张入口卡 + 侧栏 4 个子操作

4 个主要子入口

  • 导入技能:从已有目录(SKILL.md + 脚本)导入。
  • 从文档学习:上传 PDF / Markdown / EPUB,AI 把文档蒸馏成技能(走 book-to-skill)。
  • AI 创建技能:跟 AI 多轮对话,把 5 维度需求整理出来,生成技能(走 yao-meta-skill)。
  • 新建工作流:Coming soon — 尚未开放。

另外两个即将推出的能力

  • Skill optimizer:技能优化器,自动诊断技能并提出建议 — Coming soon。
  • 改用空白新建技能:跳过 AI,自己写 SKILL.md 起手。
典型场景: 你希望把某个流程固化下来,不必每次重新教 AI — 把 SOP 丢进「从文档学习」、把需求丢进「AI 创建技能」、把已有脚本丢进「导入技能」,都会产出一个可复用的技能。

10 · 设置 (Settings) — 设置中心

10

设置 (Settings) 是什么?

Settings 不是单一页,而是 9 个子分页。点击 Settings 后,左侧会出现子菜单,右侧是具体设置项。

10-settings.png · Settings 9 子菜单,默认进入「对话」分页

9 个子分页

  • 对话 (Conversation):当前会话的导出(记录 / JSON)、导入、清空。
  • 外观 (Appearance):主题(light / dark / system)、皮肤(hermes-skin 18 种)、字体大小、accent 颜色、跳转按钮开关。
  • 偏好 (Preferences):默认模型、reasoning 默认、context threshold、流式模式、队列行为、压缩策略。
  • 提供商 (Providers):API 密钥管理 — 添加 / 编辑 / 删除每个 AI provider。
  • 插件 (Plugins)(默认隐藏):已安装的 QAgent 插件 + 生命周期钩子只读视图。
  • 扩展 (Extensions):WebUI 扩展管理(三个子 tab:Gallery / Installed / Diagnostics)。
  • 系统 (System):实例版本、访问控制(密码 / passkey / 登录方式)。
  • 账户 (Account):账号信息(用户名 / 邮箱 / 登录方式)、登出。
  • 帮助 (Help):文档链接、工单 / 支持联系方式、版本信息。
异常状态提示: 如果你的登录态有异常,Settings 右上角会出现一个红色小圆点 — 点开 Settings,系统会指引你完成修复。

总结 · 这 4 个模块机制是如何解决问题的

前面 10 个模块是 UI 形态。从设计机制的角度看,QBuilder 的核心只做四件事,各自对应一组模块的组合:

  1. 让 AI 跨会话持续学习你 — Memory。「我的备注 / 用户画像 / 智能体灵魂 / 项目上下文」四栏把零散的偏好、判断、人格、项目背景变成 AI 跨对话可读的结构化记忆。下次开会话,它带着这些继续。
  2. 把行业 know-how 固化成可插拔资产 — Skills + Skill Studio。Skills 是带 SKILL.md + 脚本的完整技能包,可从文档蒸馏生成(从文档学习)、AI 多轮问答生成(AI 创建技能)、本地目录导入(导入技能),由 Skill Studio 统一生产。Skills 是 Skills,Skill Studio 是 Skills 的制造车间 — 一边消费、一边生产。
  3. 让智能体进入用户已有的工具 — Channels。Channels 把 QBuilder 对接到微信 / 企微 / Telegram 等用户已经在用的聊天平台,客户 / 学生不必切换工具。Service Page(交付发布)是另一种「交付渠道」,给独立 chat 页面 + 自定义子域名。
  4. 把重复劳动交给调度系统 — Tasks + 多工作区 + 多 Agent profile。Tasks 让对话按 cron 跑(每天 9 点自动跑客户日报),多工作区让多个项目目录独立不互相污染,多 Agent profile 让同一台机器上不同场景用不同的「人格 + 模型 + 技能组合」。Skill Studio 即将推出的「工作流」会继续补这块 — 但当前这三层已经能撑住 80% 的自动化场景。

这四件事不是孤立的。用户在 Chat 提问时,Memory 自动注入上下文;Skills 让回答贴你的行业;Tasks 帮你定时跑日报;Channels 让你的客户在微信里直接跟这个智能体聊 — 四组模块首尾相接,拼成「把你脑里的方法论变成客户可用的产品」这一条完整业务闭环。这也是开头那句定位 — 「把『我脑子里那套方法论』变成一个能被客户随时用的产品」 — 在控制面板层面的具体落地路径。
