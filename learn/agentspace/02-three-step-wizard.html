三步发布向导:身份 · 收费 · 上线

从「技能库」页勾选的卡点进来,走完身份 → 收费 → 上线三步,你的智能体就正式对外了。

PATH 01 · 启程 约 5 分钟读完 实操约 5–10 分钟 最后更新 2026-09
本教程适合谁? 已经在「技能库」页勾选了一张卡(或几张)、准备好让智能体对外服务的创作者。读完你会知道三步里每一步都填什么、哪些字段留空也允许、以及点「确认上线」那一刻可能遇到的三种失败。

这是 PATH 01「启程」的第 2 课。整条路径:

  1. 把技能同步进智空间(上一课)
  2. 三步发布向导:身份 · 收费 · 上线(本课)
  3. 拿到第一个链接与二维码(下一课)
  4. 走查访问者视角
  5. 改完「更新版本」才生效

开始之前

从「技能库」页勾选一张卡 + 点右下角的「发布为智能体」,会进入「发布向导」页(在浏览器里)。这个向导分三步 — 你可以随时点上方的步骤标签来回切,但「确认上线」只能在第三步点。

关键前置: 如果你部署的是 direct 模式(没有平台模型网关),第一步顶部会出现一张红色提示卡,强制你点「去配置密钥」配自己的模型密钥 — 没配就不能往下走。如果你已经配好,这张卡不会出现。

步 1:身份

这一步把所有"让访问者一眼认识这个智能体"的字段填齐。表单从上到下分六块:

必填

智能体名称

必填

会显示在卡片标题、对话窗口标题、以及访问者分享链接时看到的第一行字。给个能让人秒懂"这智能体能干啥"的名字 — 后续所有页面的引用、消息推送、智空间卡片都用这个名字。

选填

角色设定

多行文本

告诉智能体"你是谁、你能做什么、什么时候该拒绝"。留空也允许 — 但开场会更机械,像个无差别助手;写几句话,后面整个对话的气质都会不一样。

写得越具体越好。比如不要写"我是一个写作助手",而是写"我是一名资深科技作者,擅长把复杂技术概念改成 200 字以内的口语化解释,只回答与编程 / AI / 工程实践相关的问题,其他话题礼貌推掉"。

选填

开场白

一行

访问者第一眼看到的大字。留空时回落成智能体名称 — 比如智能体叫"代码审计员",访问者看到的就是"代码审计员",不再多一行欢迎语。建议写一句"我是做什么 + 我能帮你 + 一个具体例子",例如:

你好,我是 Code Auditor — 把你的 diff 贴给我,我帮你找出潜在的并发、边界条件、安全问题。一段 diff 通常 30 秒内能给到意见。
选填

输入框提示语

一行

桌面输入框里的灰色占位符。留空用默认值 「把你的问题告诉我。」。可逐智能体定制 — 让访问者知道"这里是用来问什么的"。比如写作类智能体可以填 「贴一段文字,我帮你改。」。

选填

引导问题

0–3 个

冷启动页面(访问者第一次打开 智能体访问页 时)会渲染成卡片,点哪个就触发哪个对话。0–3 个都行 — 写得好可以显著降低访问者的"第一次对话成本"。

卡片标题和实际发出去的提问填一样的就行(都是给访问者看的)。例如:

  • 卡片标题和实际提问都填 「帮我审一段 Python 代码」
  • 卡片标题和实际提问都填 「找一处并发 bug」
  • 卡片标题和实际提问都填 「讲讲这函数的时间复杂度」
必选

运行引擎

二选一

两个选项,首次发布建议选 opencode(兜底更稳):

引擎 适合 成本
opencode 通用编码、资料检索、问答、文档生成 — 大多数场景 基线
hermes 需要"产出文件、报表、文档"等实物的工作流 同类任务 token 消耗约为 opencode 的 3 倍

后续想换引擎 — 不是这一步能改的,要去「智能体详情 · 配置」编辑对话框里改(详见 PATH 05 进阶)。

步 2:收费

这一步只有两个选项 — 二选一,没法同时存在。

选项 A

免费

默认

智能体的每一轮都不扣点,访问者也不会看到任何价格。如果你刚上线想先试水,先用这个。

选项 B

按轮扣点

两件套

同一访问者前 N 轮免费,第 N+1 轮起每轮扣 单价 点。

  • 免费轮次:默认 0(立即开始扣)。可填 1、2、3 … 给新访问者一点"试聊"机会。
  • 单价:允许两位小数。展示形如「2 点 / 轮」(约 ¥0.02 / 轮)。

三个常见组合:

单价 访问者体验
0 2 每一轮扣 2 点
3 1 前 3 轮免费,第 4 轮起每轮扣 1 点
10 5 前 10 轮免费,第 11 轮起每轮扣 5 点 — 用作"先深度体验"
关于钱的两条事实:
  • 扣的是你自己的点数(创作者钱包),不是访问者付钱给你 — 没有第三方支付、没有平台服务费、没有提现。
  • 扣点在回合结束时执行,所以最后一轮可能把你的余额扣成负数,但 UI 仍会显示余额。

步 3:上线

这一步决定智能体怎么"对外被找到"。四个开关,前两个必看,后两个看你的运营策略。

字段 1

地址后缀

2–50 位字符串

智能体的访问地址由「你的域名 + 智能体访问页路径」组成。地址后缀留空会让后端自动生成(可后续改),但自动生成的字符串通常不那么好记 — 建议自己想一个。

命名规则:

  • 小写字母、数字、连字符(-)
  • 以字母或数字开头(不能以 - 开头)
  • 总长度 2–50 位
  • 已被你的其他智能体占用的话,会被实时拒绝(输入框会变红)

几个示例:

  • code-auditor · writing-coach · math-tutor-7
字段 2

主题色

五色单选

五色单选:amber(金) / blue(蓝) / emerald(绿) / rose(粉) / violet(紫)。主题色会出现在两个地方:

  • 智能体页 智能体访问页 — 冷启动能力块、按钮、产出侧栏强调色。
  • 智空间卡片 — 头像字颜色和"推荐"角标颜色。

主题色是品牌气质的一部分,跟你的定位/受众有关 — 教学类常用 blue 或 emerald,情感/创作类常用 rose 或 amber,工具/技术类常用 violet。

开关 1

需要密码访问?

可选开关

开启后,弹窗让你输入 4 位以上密码 — 访问者必须先输对密码才能进对话页。适合:

  • 内测阶段不想公开链接
  • 只对特定客户群开放的咨询类智能体
  • 教学场景里只给某班学生

密码错会返回 passwordInvalid(HTTP 403)— 不是 401,所以不会触发刷新流程;用户重输就好。

开关 2

出现在智空间?

默认勾选

如果你已经建过智空间,这里默认勾选 — 勾上之后,智能体 ID 会被加到智空间的 智空间的智能体顺序 顶端,自动出现在 你的智空间主页 的列表最前面。

还没建智空间? 这个开关即使勾了也不会生效 — 因为没有 智空间配置 可以挂。要先到 「智空间」配置页(顶栏「智空间」)建好之后,这个开关才真正起作用。

点「确认上线」之后会发生什么

点完「确认上线」,向导会按以下顺序提交:

  1. 把 6 个身份字段 + 运行引擎一次性写进智能体配置
  2. 把 收费三件套(免费 / 按轮扣点 + 免费轮次数 + 单价)写进去(保存即生效,不必等「更新版本」)
  3. 把 地址 / 主题色 / 密码 写入
  4. (可选)如果勾了「出现在智空间」,把这个智能体加到智空间主页列表的最前面

成功时:toast 提示 + 跳到「智能体详情 · 概览」页。

失败时,有三种分支:

  • engine_not_supported(后端不接受你选的引擎):自动退回步 1,引擎选择器旁边就地显示错误提示 — 不会弹 toast。改个引擎再点上线。
  • llm_credential_missing(direct 模式下模型密钥缺失):留在步 1,顶部那张红色提示卡就地显示(带 trace_id),也不会弹 toast。回「账号设置 → 模型与密钥」页面配好再来。
  • 其它失败:toast 提示(同样带 trace_id),留在步 3 让你改完再试。

上线完,接下来能干什么

点完「确认上线」跳到「智能体详情 · 概览」页。这个页面有 7 个 tab,你会在后续 PATH 学到 — 这里先告诉你哪个 tab 改什么、要不要"更新版本":

tab 改的东西 要不要"更新版本"
概览 overview 看今日对话 / 累计对话 / 本月消耗 —
配置 config 身份、开场、主题色、引导问题 + 已装配技能 要
技能 skills 全技能库 + 勾选 + 保存 要
版本 versions 回滚到某一版(把那个 bundle 重新激活) —
数据 data 看 N 日对话 / 热门任务 / 最近任务 —
收费 pricing 修改收费三件套 不用 — 保存即生效
分享 share 访问地址、二维码、链接预览卡、API 密钥 —

第三课 拿到第一个链接与二维码 会聚焦 share tab — 拿到对外可分享的链接和二维码,这才算 PATH 01 走完。

常见踩坑

  • 地址后缀已被占用: 输入框会实时变红 + 显示「已被使用」;换一个新的就好。
  • 不写角色设定直接发布: 不是错,但开场会很机械 — 访问者会问"你是谁"得到一个无差别的回答。建议至少花 30 秒写 2 句话。
  • 选了 hermes 但没意识到成本: hermes 同类任务 token 消耗约为 opencode 的 3 倍 — 如果你钱包余额不多,先用 opencode 跑一段时间,看数据再决定。
  • 勾了"出现在智空间"但智空间还没建: 不会有错误提示,但功能也没生效 — 你会发现 智空间主页 看不到这张卡。回「智空间」配置页先把智空间建好。
  • 改完「确认上线」发现忘了字段: 直接去「智能体详情 · 配置」编辑 — 改完点右上角的「更新版本」对访问者生效;改收费直接保存即可。
