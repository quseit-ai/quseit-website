把技能同步进 QUSEIT

从 QBuilder 客户端一键推送技能包,或手动把 .zip 上传到技能库 — 两分钟让你的第一个技能入库。

PATH 01 · 启程 约 3 分钟读完 实操约 2 分钟 最后更新 2026-09
本教程适合谁? 刚在 QBuilder 里做出第一个技能、准备把它发到 QUSEIT 的创作者。读完你会知道两条同步路径怎么选、上传后怎么在「技能库」页核对标记,以及怎么勾选发布成智能体。

这是 PATH 01「启程」的第 1 课。后面还有 4 课,跑完你就会拿到第一个上线链接:

  1. 把技能同步进 QUSEIT(本课)
  2. 三步发布向导:身份 · 收费 · 上线
  3. 拿到第一个链接与二维码
  4. 走查访问者视角
  5. 改完「更新版本」才生效

开始之前

无论走哪条路,你的技能包必须满足一个硬条件:包里要有 SKILL.md。

  • 技能包根目录有 SKILL.md(大小写敏感)。
  • SKILL.md 里写了 name / description / instructions 三件套,具体怎么写见 QBuilder 教程的「5 分钟创建你的第一个智能体」。
  • 整个压缩包 ≤ 200 MB(超过会被前端直接拦截)。
直连还是走网关? 如果你部署的是 direct 模式(没有平台模型网关),这一课要确保你已经在 「账号设置 → 模型与密钥」页面配了自己的模型密钥 — 否则后面第 2 课的发布按钮会被红卡拦截,这里先查好。

两条路,先选一条

QUSEIT 的「发布技能」页给了两条同步路径:

路径 触发方式 技能标记 适合
路径 A · QBuilder 对话触发同步 在 QBuilder 对话里让 Agent 推送 来自 QBuilder 日常迭代、改了再发(顺带直接发布成智能体)
路径 B · 手动上传 zip 在「发布技能」页拖文件 自建(默认类别 未分类) 没有客户端、一次性导入

默认推荐路径 A:它带上你的登录态,服务端无需再做身份校验,而且技能标记是「来自 QBuilder」 — 后面在技能库里筛选时一眼就能找出本地迭代的版本。路径 B 是给「我只有个 zip 包、没有 QBuilder 客户端」这种场景准备的。

路径 A · 从 QBuilder 对话触发同步(推荐)

STEP 01

在 QBuilder 里完成技能的构建

几分钟到几十分钟

在 QBuilder 桌面端里把技能写到能跑通:本地的 SKILL.md、示例输入输出、必要的工具挂载 — 这些都在 QBuilder 客户端里完成,具体怎么写见 QBuilder 教程的「5 分钟创建你的第一个智能体」。

关于登录态: 第一次同步前,客户端会引导你关联 QUSEIT 账号(凭票 + SSO,10 分钟内有效);关联完成后,以后每次同步都不用再输密码。
STEP 02

在 QBuilder 对话里让 Agent「将技能发布到智能体空间」

约 1 分钟

技能构建完成后,继续在 QBuilder 对话里跟 Agent 协作,告诉它「将技能发布到智能体空间」。客户端会带登录态,主动把技能包推过来;服务端按 SKILL.md 校验后入库。

同步完成后,技能自动出现在「技能库」页,卡片上会标记「来自 QBuilder」。

STEP 03

在「技能库」页勾选技能,点击右下角的「发布为智能体」

约 2 分钟

在「技能库」页找到刚才从 QBuilder 推过来的那张卡(标记「来自 QBuilder」),勾选卡片右上角的复选框 — 至少勾 1 个时,底部会出现常驻条,右下角的主按钮是「发布为智能体」。点击后进入三步发布向导(身份 → 收费 → 上线),这部分的细节会在 PATH 01 第 2 课展开。

  • 若列表没出现 — 看 QBuilder 对话里的报错;常见原因是 SKILL.md 缺字段或包结构有问题。
  • 勾选后没看到「发布为智能体」按钮 — 检查是否真的勾上了(卡片会变成金色描边)。
注意:你这次看到的是「技能库」页(不是浏览器里那个「发布技能」页)。同步动作由 QBuilder 客户端发起;勾选 + 「发布为智能体」这条动作在浏览器里完成。

路径 B · 手动上传 zip

STEP 01

把技能打包成 .zip

约 1 分钟

把整个技能目录打包成 .zip。包根目录必须直接包含 SKILL.md — 不要把它再套一层目录。

  • macOS / Linux: zip -r my-skill.zip ./my-skill
  • Windows: 在资源管理器里右键 → 压缩到 .zip
  • 把 SKILL.md 放到子目录里 → 服务端找不到,直接报错。
  • 压缩包超过 200 MB → 前端直接拦截,后端根本收不到。
STEP 02

拖到上传卡片

约 30 秒

在「发布技能」页,有两种交互:点「选择文件」按钮弹出文件选择器,或者直接把 .zip 拖到卡片上。单文件 ≤ 200 MB。

STEP 03

跳回技能库核对

约 30 秒

上传成功后会自动跳回「技能库」页。新技能显示在列表里,标记为「自建」、默认类别「未分类」(你需要后续手动给它分类)。下一步:勾选这张卡,点右下角的「发布为智能体」,走三步发布向导。

上传完,接下来该看哪里

走完本课你已经在「技能库」页看到那张卡。路径 A 通常在三步发布向导里就能直接发布成智能体;路径 B 需要回到「技能库」页,勾选后点「发布成智能体」,才走完从「技能」到「智能体」的最后一步。

在「技能库」页核对一下,这张卡应该是这样:

  • 来源标记正确(「来自 QBuilder」/「自建」)
  • 分类已设置(路径 A 通常自动跟 QBuilder 一致;路径 B 默认「未分类」,需要手动改)
  • 技能详情里 SKILL.md 全文可读
  • 暂未被任何智能体使用(下一步才会勾选)

核对完毕 → 进入第 2 课「三步发布向导」,详细走一遍身份 / 收费 / 上线三件事。

常见踩坑

  • 想用路径 A 但客户端没登录: 第一次同步会被引导走 SSO 关联(凭票跳到 SSO 登录页,10 分钟内有效)。密码连续输错会让凭据失效,得回客户端重发。
  • 路径 B 上传后看到「未分类」: 这是预期行为 — zip 上传没有客户端携带的分类元数据,服务端给一个「未分类」占位,需要你在技能库里手动改。
  • 想删技能但删不掉: 弹窗底部会显示「正在被 N 个智能体使用」 — 凡是还有引用的都不能删,先去那些智能体里换掉再回来删。
